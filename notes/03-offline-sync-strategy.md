# 오프라인 동기화 전략

> LLM Wiki — Hive + Firestore 동기화 구현 기록  
> 작성자: 혜지

## 아키텍처 이해

```
온라인: Provider ↔ Firestore
오프라인: Provider ↔ Hive
복구 시: Hive → Timestamp 비교 → Firestore 동기화
```

## Last-Write-Wins 전략
- 로컬 수정 시간 > 서버 수정 시간 → 로컬을 서버에 업로드
- 서버 수정 시간 > 로컬 수정 시간 → 서버 데이터를 로컬에 저장
- 동일 → 사용자가 선택
