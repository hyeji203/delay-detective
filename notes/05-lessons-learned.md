## AI와 협업할 때 잘 되는 방식

### 잘 되는 것 ✅

**1. 역할 분리 + 결과물 명시 호출**
```
"backend-architect야, HiveService 만들어줘.
파일: lib/services/hive_service.dart
메서드: addTask, getTask, updateTask, deleteTask"
```
→ 형식이 맞게 나오고 재작업이 적음

**2. "왜?" 질문으로 이해 확인**
```
에이전트가 코드 생성 → "이 부분 왜 이렇게 했어?" → 이해 후 적용
```
→ 발표에서 직접 설명 가능

**3. 단계별 검증**
```
코드 생성 → 즉시 실행 → 동작 확인 → 다음 단계
```
→ 나중에 몰아서 디버깅하는 것보다 훨씬 빠름

**4. AUTHORING.hyeji.md를 세션 시작마다 붙여넣기**
→ 에이전트가 프로젝트 맥락을 즉시 파악

---

### 잘 안 되는 것 ❌

**1. 너무 큰 단위로 한 번에 요청**
```
"앱 전체 만들어줘" → 에이전트가 방향을 잡지 못하거나 너무 단순하게 구현
```

**2. 에이전트 결과를 이해 없이 바로 복사**
```
→ 버그 발생 시 원인 파악 불가능, 발표 시 설명 불가능
```

**3. 여러 에이전트에게 같은 파일을 동시에 수정 요청**
```
→ 충돌 발생. 한 파일은 한 에이전트가 담당하도록 분리
```
