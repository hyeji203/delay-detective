신혜지  ·  중간 발표  ·  2026-06-08

안녕하세요. 딜레이 디텍티브를 개발 중인 신혜지입니다. 이 앱은 Flutter + Claude API로 만드는 AI 할일 관리 앱이고요, 핵심은 '왜 미루는지'를 AI가 찾아주는 겁니다. (15초)

왜 만들었나 — 문제 정의

"할일 앱은 넘쳐나지만, 사람들은 여전히 미룬다."

❌ 기존 앱의 가정

  • 리스트에 적으면 한다
  • 알림을 보내면 한다
  • 마감일을 보여주면 한다

✅ 실제로 필요한 것

  • 왜 미루는지 이유 파악
  • 시작점을 15분으로 쪼개기
  • AI의 공감 + 실행 첫 걸음
💡 미루는 건 의지 문제가 아니라, 아직 해결되지 않은 마찰(friction)이다.
기존 앱은 기록만 하고 끝입니다. 왜 못 시작하는지는 아무도 물어보지 않아요. 저는 그게 핵심 문제라고 봤습니다. (35초)

기술선택 이유
FlutteriOS · Android 단일 코드베이스 — 한 번 개발, 두 플랫폼 동시 지원
Provider단순한 상태 관리 — ChangeNotifier로 화면 자동 갱신
Hive오프라인 우선 로컬 DB — 네트워크 없이도 즉시 저장
Firestore실시간 클라우드 동기화 — 멀티 디바이스 동일 데이터 유지
Claude API3턴 고정 인터뷰 — 비용 제어 + 미루는 이유 맞춤 분석
🔄 Offline-First: Hive 즉시 저장 → 복구 시 Firestore 동기화 (Last-Write-Wins)
왼쪽은 4-레이어 구조, 오른쪽은 각 기술 선택 이유입니다. Flutter로 iOS·Android 동시 지원, Hive로 오프라인, Firestore로 동기화, Claude API 3턴 고정으로 비용 제어합니다. (23초)
