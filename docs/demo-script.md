## 데모 시나리오 (시나리오 A 기반)

**상황**: "발표 과제 마감 3일 전인데 아직 시작을 못 했어요"

```
1. 홈 화면 열기
   → "발표 준비" 태스크에 🔴 지연 배지 표시 확인

2. "AI에게 물어보기" 버튼 탭
   → AI 인터뷰 화면으로 이동

3. AI 인터뷰 진행 (2~3턴)
   AI: "뭐가 제일 막히나요?"
   입력: "어디서부터 해야 할지 모르겠어요"
   AI: "주제 조사 vs 자료 구성 중 어느 쪽이 더 막막해요?"
   입력: "자료 구성이요"

4. 분석 결과 화면 확인
   ① 공감: "흐름이 안 잡혀서 시작을 미루고 있는 거예요"
   ② 원인: "완벽한 구성을 먼저 만들려는 압박이 원인이에요"
   ③ 소태스크 3개 체크박스

5. 소태스크 하나 완료 체크
   → 홈 화면에서 진행률 업데이트 확인
```
