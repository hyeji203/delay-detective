## 1. 핵심 사용자 시나리오 3개

---

### 시나리오 A — "마감이 다가오는데 시작을 못 하겠어"

**사용자**: 수현 (대학생, 발표 과제 3일 후 마감)

```
상황:
  발표 과제를 등록할 때 마감일을 설정해뒀다.
  D-3이 됐는데 아직 손도 안 댔다.

앱의 행동:
  1. 홈 화면에 "발표 준비 — 지연 감지됨 🔴" 표시
  2. "AI에게 물어보기" 버튼 탭
  3. AI 인터뷰 시작:
     AI: "발표 준비, 아직 시작 못 했군요. 뭐가 제일 막히나요?"
     수현: "어디서부터 해야 할지 모르겠어요"
     AI: "주제 조사부터인지, 발표 자료 구성부터인지 중 뭐가 더 막막해요?"
     수현: "자료 구성이요, 어떻게 흐름을 짜야 할지"
  4. AI 분석 결과:
     ① "흐름이 안 잡혀서 시작 자체를 미루고 있는 거예요. 흔한 패턴이에요."
     ② "구성이 완벽해야 시작할 수 있다는 압박이 원인이에요."
     ③ 소태스크:
        - [ ] 발표 주제 한 줄로 써보기 (5분)
        - [ ] 말하고 싶은 내용 3개만 메모 (10분)
        - [ ] PPT 빈 슬라이드 5개 제목만 채우기 (10분)

결과: 수현는 "5분짜리 한 줄 쓰기"부터 시작해서 과제를 완료했다.
```

---

### 시나리오 B — "계속 미루던 개인 목표, 이번엔 왜인지 알고 싶어"

**사용자**: 민준 (25세 직장인 겸 자격증 준비생)

```
상황:
  "운동 루틴 만들기" 태스크를 2주째 미루고 있다.
  직접 "이거 계속 미루고 있어요" 버튼을 눌렀다.

앱의 행동:
  1. "얼마나 됐어요?" → "2주 됐어요"
  2. AI 인터뷰:
     AI: "2주째 미루고 있군요. 운동 자체가 싫은 건지, 
          루틴 짜는 게 귀찮은 건지 어느 쪽에 가까워요?"
     민준: "루틴 짜는 게 너무 복잡하게 느껴져요"
     AI: "완벽한 루틴을 한 번에 만들려고 하는 느낌인가요?"
     민준: "맞아요, 어떤 운동부터 해야 할지 찾다가 지쳐요"
  3. AI 분석 결과:
     ① "완벽한 루틴을 설계하려다 시작 자체를 못 하는 상태예요."
     ② "정보 과부하로 인한 결정 마비(Decision Paralysis)가 원인이에요."
     ③ 소태스크:
        - [ ] 오늘 퇴근 후 10분만 걷기 (루틴 없이)
        - [ ] 걷고 나서 느낌 한 줄 메모
        - [ ] 다음날 앱에서 "어땠어요?" 체크

결과: 루틴 설계 대신 "일단 10분 걷기"로 시작점을 낮춰 실행했다.
```

### 시나리오 C — "여러 과목이 겹쳐서 뭐부터 해야 할지 모르겠어"

**사용자**: 유진 (중간고사 기간, 과목 4개가 동시에 마감)

```
상황:
  과목 A 레포트, 과목 B 발표, 과목 C 팀플, 과목 D 시험이
  모두 같은 주에 겹쳐있다.
  홈 화면에 지연 태스크 3개가 동시에 빨간 불이 들어왔다.

앱의 행동:
  1. 홈 화면에 지연 태스크 우선순위 자동 정렬
     (마감일 임박 + 예상 소요시간 기준)
  2. 가장 급한 태스크 "과목 A 레포트" 선택 → AI 인터뷰:
     AI: "레포트 마감이 내일인데, 지금 어느 단계예요?"
     유진: "주제만 정하고 아무것도 못 했어요"
     AI: "지금 남은 시간이 몇 시간이에요?"
     유진: "오늘 저녁 3시간 정도요"
  3. AI 분석 결과:
     ① "3시간으로 완성 가능한 범위로 바로 좁혀드릴게요."
     ② "전체를 쓰려는 부담감이 시작을 막고 있어요."
     ③ 소태스크 (3시간 한정):
        - [ ] 서론 + 결론 먼저 초안 (60분)
        - [ ] 본론 핵심 주장 2개만 (80분)
        - [ ] 참고문헌 3개 추가 (20분)
        - [ ] 전체 흐름 한 번 읽기 (20분)

결과: "3시간 안에 다 쓰기" 계획이 명확해져서 실행에 돌입했다.
```

## 2. MoSCoW 기능 분류

### Must Have (없으면 앱이 아님)

| 기능 | 설명 |
|---|---|
| 태스크 CRUD | 생성·조회·수정·삭제, 마감일·우선순위 설정 |
| 지연 감지 — 자동 | 마감일 초과 시 자동으로 "지연됨" 상태 전환 |
| 지연 감지 — 수동 | 사용자가 직접 "미루고 있어요" 버튼으로 표시 |
| AI 챗봇 인터뷰 | Anthropic API, 2~3턴 대화로 원인 파악 |
| AI 분석 결과 출력 | 공감 한 줄 + 원인 요약 + 소태스크 3개 이하 |
| Hive 로컬 저장 | 로그인 없이도 데이터 영구 보관, 오프라인 동작 |

---

### Should Have (있어야 제대로 된 앱)

| 기능 | 설명 |
|---|---|
| 푸시 알림 | 마감 D-3, D-1, D-day 알림. 지연 태스크 리마인더 |
| 선택적 Firebase 로그인 | 게스트 모드 기본, 원하면 로그인해서 동기화 |
| Firestore 동기화 | 로그인 시 멀티 디바이스 동기화 활성화 |
| Hive ↔ Firestore 동기화 | Timestamp 기반 Last-Write-Wins Conflict Resolution |
| AI 인터뷰 히스토리 | 과거 분석 결과 다시 보기 |
| 소태스크 완료 체크 | AI가 제시한 소태스크 체크박스로 실행 추적 |

---

### Could Have (있으면 좋지만 나중에)

| 기능 | 설명 |
|---|---|
| 통계 & 차트 | 내 지연 패턴 시각화 (어떤 요일, 어떤 태스크 유형이 많이 미뤄지는지) |
| Notion MCP 연동 | AI 분석 결과를 노션에 자동 저장 |
| GitHub MCP 연동 | 소태스크를 깃허브 이슈로 자동 생성 |
| 태스크 우선순위 자동 정렬 | 마감일 + 예상 소요시간 기반 자동 순위 |
| 다크모드 | 시스템 다크모드 연동 |
| 홈 화면 위젯 | 오늘의 지연 태스크 요약 위젯 |

---

### Won't Have (이번 버전에서 하지 않음)

| 기능 | 이유 |
|---|---|
| 캘린더 연동 (Google/Apple) | 범위 초과, 추후 버전에서 고려 |
| 팀·협업 기능 | 개인 앱으로 먼저 검증 필요 |
| Flutter Web 배포 | 모바일 우선, 안정화 후 추가 |
| Apple Watch / 위젯 (복잡한 것) | 네이티브 확장 필요, 범위 초과 |
| 소셜 기능 (친구 공유, 랭킹) | 핵심 가치와 무관 |

---

## 3. 기능 우선순위 요약

```
세션 3-4 (Must):
  태스크 CRUD → Hive 저장 → 지연 감지 → AI 인터뷰 → 결과 출력

세션 4-5 (Should):
  Firebase 로그인 → Firestore 동기화 → 충돌 해결 → 알림

세션 6 (Could — 시간 되면):
  통계 화면 → MCP 연동 → 다크모드
```
